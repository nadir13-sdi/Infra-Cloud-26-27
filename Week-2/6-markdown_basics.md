# Markdown Basics

Markdown is handig voor Jupyter Notebooks en GitHub repositories.

## Formatting
- **Vetgedrukt**: `**tekst**`
- *Cursief*: `*tekst*`
- ***Vet & Cursief***: `***tekst***`

## Lijsten
### Unordered List
- Python
- Ansible
- Terraform
- Docker

### Numbered List
1. Install Python
2. Create a virtual environment
3. Install the packages
4. Run the application
